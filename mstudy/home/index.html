MStudy

SES Student Productivity Tool

Application Purpose

MStudy is an independent, specialized educational companion application built exclusively for students at SES. The purpose of this application is to enhance personal academic productivity by aggregating reference materials, compiling localized study tools, and tracking relevant assignment schedules in a centralized student dashboard.

Core Features

  • Dashboard Syncing: Keep track of upcoming deadlines, class task details, and assignment metadata.
  • Study Guides & Flashcards: Compile, access, and review peer-to-peer study materials directly within the system.
  • Classroom Indexing: Seamlessly organize and link out to public Google Classroom structural resources for quick reference.
